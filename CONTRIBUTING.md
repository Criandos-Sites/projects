# Como adicionar um projeto

Abra uma solicitação pelo formulário do repositório. A curadoria verifica se a página está acessível e inclui o projeto no `projects.json`.

Cada item usa este formato:

```json
{
  "name": "Nome do projeto",
  "url": "https://pagina-publicada.example",
  "description": "Descrição curta do projeto.",
  "author": "Nome do criador",
  "code": "https://github.com/usuario/repositorio"
}
```

`author` e `code` são opcionais e podem ser omitidos.
