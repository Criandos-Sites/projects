# Projetos da comunidade

Vitrine de páginas e aplicações criadas por participantes da comunidade Criandos Sites.

## Compartilhe seu projeto

Use o formulário em [criandos-sites.github.io](https://criandos-sites.github.io/#enviar-projeto) para enviar pelo WhatsApp ou pelo GitHub.

Para participar, informe:

- nome do projeto;
- link público da página;
- descrição curta;
- nome do criador, se quiser;
- link do código, se quiser.

O código-fonte **não é obrigatório**. O projeto pode ser incluído mesmo quando o repositório é privado ou não existe.

## Como a vitrine é atualizada

Os projetos aprovados entram no arquivo [`projects.json`](./projects.json). A página pública lê esse arquivo automaticamente.
